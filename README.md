# 🌐 Homelab Appliance & Transparent Gateway

[![Linux](https://img.shields.io/badge/Linux-Arch%20%7C%20Debian%20%7C%20Ubuntu-1793d1?style=for-the-badge&logo=linux&logoColor=white)](https://github.com/unknownpeace/arch-homelab-gateway)
[![Docker](https://img.shields.io/badge/Docker-Engine%2027%2B%20%7C%20Compose%20v2-2496ed?style=for-the-badge&logo=docker&logoColor=white)](https://www.docker.com/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)
[![Release](https://img.shields.io/badge/Release-2026%20Core-blueviolet?style=for-the-badge)](https://github.com/unknownpeace/arch-homelab-gateway)

Полностью автоматизированный программно-аппаратный комплекс для превращения домашнего сервера, мини-ПК (x86) или одноплатника в **высокопроизводительный прозрачный шлюз (Smart Gateway)**, защищённое сетевое хранилище (**NAS с шифрованием LUKS2**) и частное микро-облако (**Self-Hosted Cloud Platform**).

## ⚡ Быстрая установка в 1 команду

Выполните команду в терминале вашего сервера (требуются права `root` / `sudo`):

```bash
 (command -v curl >/dev/null 2>&1 && curl -fsSL "https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/refs/heads/main/install.sh" -o install.sh || wget -qO install.sh "https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/refs/heads/main/install.sh") && chmod +x install.sh && sudo ./install.sh
```

> **Примечание:** Скрипт полностью **идемпотентен**. Повторный запуск не ломает существующие настройки, мгновенно проверяет уже установленные пакеты, не перезапускает Docker без необходимости и не скачивает повторно базы гео-данных или веб-интерфейсы.

## 🚀 Ключевые возможности

### 1. Прозрачный сетевой шлюз (Smart Gateway)
* **Аппаратная замена OpenWrt / OpenClash:** Весь трафик маршрутизируется x86-процессором сервера с околонулевыми задержками и поддержкой скоростей до 10 Гбит/с без троттлинга.
* **Mihomo TUN (Clash Meta):** Интеллектуальный роутинг по базам GeoIP и GeoSite (российские сервисы, банки, Госуслуги идут напрямую, замедляемые и заблокированные ресурсы — через прокси).
* **AdGuard Home:** Фильтрация рекламы на уровне DNS для всей домашней сети, встроенный DNS-over-HTTPS/TLS.
* **Анти-петлевой сторожевой таймер:** Фоновая служба `network-gateway-watchdog.timer` предотвращает зацикливание маршрутов даже при внезапной перезагрузке роутера или смене IP.

### 2. Защищённое хранилище и диски (Encrypted NAS)
* **Аппаратное шифрование LUKS2:** Защита дисков мастер-ключом с генерацией служебного keyfile и автоматической разблокировкой при загрузке сервера.
* **Файловая система Btrfs:** Автоматическое отключение Copy-on-Write (`chattr +C`) для каталогов баз данных SQLite и торрент-загрузок для максимальной скорости ввода-вывода.
* **Сетевой доступ Samba (SMB):** Поддержка Windows Network Discovery (`wsdd2`), мгновенное обнаружение в проводнике Windows, macOS Finder и мобильных клиентах.

### 3. Автоматический HTTPS и сертификаты (Caddy v2)
* **Режим *.lan (Локальный CA):** Автоматическая генерация доверенного корневого сертификата (`caddy-root.crt`) для всех внутренних сервисов. Сертификат автоматически публикуется в сетевую папку SMB для удобной установки на смартфоны и ПК.
* **Режим DuckDNS + Let's Encrypt:** Получение доверенного публичного Wildcard SSL-сертификата через DNS-01 Challenge без необходимости открывать 80/443 порты наружу.

### 4. Комплекс Self-Hosted сервисов
* **Vaultwarden:** Легковесный сервер Bitwarden на Alpine с автоматическим хэшированием пароля администратора через Argon2id.
* **Gitea:** Полноценный Git-сервер с автоматической инициализацией пользователя-администратора (без ручного визарда первой настройки).
* **qBittorrent + VueTorrent:** Торрент-клиент с современным адаптивным веб-интерфейсом VueTorrent, преднастроенным мастер-паролем и защитой от перехвата портов.
* **MeTube:** Простой и удобный веб-интерфейс для скачивания видео и аудио через `yt-dlp`.
* **Горячее резервное копирование:** Встроенный таймер `vaultwarden-backup.timer`, создающий атомарные бэкапы баз данных SQLite без остановки контейнеров.

## 🎛️ Режимы развёртывания

При запуске скрипт предлагает 3 сценария:

1. **`[1] Экспресс-установка (Zero-Touch)`**  
   Идеально для быстрого старта: включает все сервисы, сохраняет данные на системном диске, настраивает локальные домены `*.lan` и генерирует единый мастер-пароль.
2. **`[2] Расширенная настройка`**  
   Интерактивный конструктор: выбор накопителей (форматирование в Btrfs, шифрование LUKS2), выбор нужных контейнеров, настройка DuckDNS Wildcard SSL и пользовательских паролей.
3. **`[3] Сброс стека`**  
   Полная остановка и удаление контейнеров, очистка конфигураций и подготовка к чистой переустановке.

## 🔌 Настройка домашнего роутера (1 действие)

Чтобы все устройства в вашем доме (смартфоны, ПК, телевизоры, планшеты) автоматически получили фильтрацию рекламы, доступ к `.lan` сайтам и обход замедлений **без установки каких-либо программ**:

1. Откройте панель управления вашего домашнего роутера (обычно `192.168.1.1` или `192.168.0.1`).
2. Перейдите в раздел **Настройки сети / DHCP**.
3. Укажите:
   * **Первичный DNS-сервер:** `IP-адрес вашего Homelab-сервера` (например, `192.168.1.47`)
   * **Основной шлюз (Gateway):** `IP-адрес вашего Homelab-сервера` (например, `192.168.1.47`)
4. Сохраните настройки и перезагрузите Wi-Fi на устройствах.

## 🛠️ Полезные команды управления

Управление стеком осуществляется через встроенный алиас `dc` (универсальный для `docker compose` и `docker-compose`):

```bash
# Просмотр статуса запущенных сервисов
dc ps

# Просмотр логов в реальном времени (всех или конкретного сервиса)
dc logs -f
dc logs -f mihomo
dc logs -f caddy

# Перезапуск всего комплекса через systemd
sudo systemctl restart homelab.service

# Остановка и запуск стека вручную
dc down
dc up -d

# Просмотр отчёта автоматической диагностики
cat /opt/homelab/diagnostic_report.log
```
