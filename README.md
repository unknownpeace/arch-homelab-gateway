# 🏠 Arch Homelab & Gateway

Комплексное решение для автоматического развертывания домашнего сервера и сетевого шлюза «всё в одном». 

Скрипт разворачивает стек изолированных сервисов в Docker, настраивает прозрачную маршрутизацию трафика, DNS-фильтрацию рекламы, защищенное хранилище (включая шифрование LUKS2), сетевую папку Samba и автоматический выпуск HTTPS-сертификатов.

---

## ⚡ Быстрое развертывание

Для установки на чистой системе выполните команду с правами root:

```bash
curl -fsSL https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/refs/heads/main/install.sh | sudo bash
```

Прямая ссылка на скрипт: [install.sh](https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/refs/heads/main/install.sh)

> **Примечание:** Если требуется предварительно сохранить и проверить скрипт локально:
> ```bash
> curl -fsSL -o install.sh https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/refs/heads/main/install.sh
> chmod +x install.sh
> sudo ./install.sh
> ```

## 📦 Состав стека сервисов

| Сервис | Описание | Адрес по умолчанию |
| :--- | :--- | :--- |
| **AdGuard Home** | Блокировка рекламы, трекеров и вредоносных сайтов на уровне всей сети | `https://adguard.local` |
| **Mihomo TUN** | Прозрачный умный шлюз с удобной панелью **MetaCubeXD** | `https://proxy.local` |
| **Vaultwarden** | Менеджер паролей (совместим с Bitwarden) со встроенным резервным копированием | `https://vault.local` |
| **qBittorrent** | Торрент-клиент с современным веб-интерфейсом **VueTorrent** | `https://torrent.local` |
| **Samba (SMB)** | Общий сетевой накопитель для Windows, macOS, Android и Linux | `\\<IP-сервера>\<Имя-папки>` |
| **Caddy** | Обратный прокси с поддержкой локального CA или публичного Wildcard SSL (DuckDNS) | Порты `80` и `443` |
| **Watchtower** | Автоматическое фоновое обновление образов и контейнеров Docker | Фоновый процесс |

## ✨ Ключевые возможности

* **Надежная синхронизация времени**: Автоматическая корректировка системных часов по HTTP и NTP перед подключением репозиториев (устраняет ошибки валидации подписей `sqv` и GPG-ключей Docker в Debian 13 и Ubuntu).
* **Сетевой шлюз и TUN**: Маршрутизация на уровне ядра (`ip_forward`, NAT/MASQUERADE, iptables), корректное отключение конфликтующего stub-резолвера `systemd-resolved`.
* **Гибкая настройка накопителей**:
  * Размещение на основном системном диске;
  * Подключение существующего раздела без форматирования;
  * Форматирование накопителя в **exFAT**;
  * Шифрование **LUKS2 (Argon2id)** с генерацией ключ-файла для автомонтирования при загрузке системы.
* **Резервное копирование**: Systemd-таймер для ежедневного создания бэкапов базы данных Vaultwarden со сжатием и автоочисткой копий старше 14 дней.
* **Безопасность учетных записей**: Единый мастер-пароль с автоматической генерацией надежных хэшей (Argon2, PBKDF2, Bcrypt) для всех веб-панелей и сетевого доступа.
* **Контроль запуска через systemd**: Служба `homelab.service` обеспечивает строгий порядок монтирования дисков, настройки сети и запуска контейнеров Docker Compose.

## 🛠 Сценарии развертывания

При запуске скрипт предлагает три режима:

1. **Экспресс-установка (`Enter`)**:
   * Развертывание всех компонентов на системном диске.
   * Использование внутренних сертификатов (`*.local`).
   * Запрос только базовых параметров: единого пароля и ссылки на подписку (опционально).
2. **Расширенная настройка**:
   * Интерактивный выбор и разметка физических накопителей.
   * Настройка шифрования LUKS2 и авторазблокировки через `/etc/crypttab`.
   * Выборочная установка сервисов (шлюз, торренты, хранилище, менеджер паролей).
   * Выбор SSL: локальный `*.local` или публичный через **DuckDNS + Let's Encrypt**.
3. **Начать сначала**:
   * Остановка контейнеров и очистка конфигурационных файлов без удаления загруженных файлов и образов.

## 🔒 Работа с зашифрованным диском (LUKS2)

Если выбран зашифрованный том без сохранения постоянного ключа в системе, для ручной разблокировки создается команда:

```bash
sudo homelab-unlock
```

Утилита запросит пароль от тома, смонтирует файловую систему и запустит Docker Compose.

## 📋 Управление и диагностика

Все рабочие файлы и конфигурации находятся в директории `/opt/homelab`.

* **Статус системной службы:**
  ```bash
  sudo systemctl status homelab.service
  ```
* **Состояние контейнеров:**
  ```bash
  cd /opt/homelab && sudo docker compose ps
  ```
* **Просмотр логов сервисов:**
  ```bash
  cd /opt/homelab && sudo docker compose logs -f [имя_сервиса]
  ```
* **Ручной запуск бэкапа:**
  ```bash
  sudo systemctl start vaultwarden-backup.service
  ```

## 🔑 Установка корневого сертификата CA (для *.local)

При локальном режиме SSL Caddy выпускает собственный корневой сертификат. Он автоматически сохраняется в папку данных:
`.../certificates/caddy-root.crt` (также доступен через сетевую папку Samba).

Установите этот файл в список доверенных корневых сертификатов ваших устройств (Windows, Android, iOS, macOS), чтобы страницы открывались по HTTPS без предупреждений браузера.
