# 🚀 Arch Homelab & Transparent Gateway

> Автоматизированный скрипт развертывания домашнего сервера, защищенного хранилища и прозрачного сетевого шлюза (TUN Gateway) на базе **Arch Linux** и **Docker Compose**.

## 📌 О проекте

Скрипт превращает компьютер или мини-ПК на Arch Linux в автономный сетевой комбайн. Он в интерактивном режиме настраивает сеть, подготавливает накопители (с поддержкой шифрования LUKS2), настраивает обратный прокси Caddy с автоматическим HTTPS и разворачивает стек необходимых сервисов.

### 🧩 Что входит в стек:

| Сервис | Назначение | Интерфейс / Доступ |
| :--- | :--- | :--- |
| **Mihomo (Clash.Meta)** | Прозрачный сетевой шлюз (TUN mode, Fake-IP, обход блокировок для всей домашней сети) | Панель управления **MetaCubeXD** |
| **AdGuard Home** | Блокировка рекламы, трекеров, вредоносных сайтов и локальный DNS-резолвер | Веб-панель DNS |
| **Vaultwarden** | Легковесный менеджер паролей (совместим с официальными приложениями Bitwarden) | HTTPS Веб-хранилище |
| **qBittorrent** | Торрент-клиент с преднастроенными путями сохранения | Современный UI **VueTorrent** |
| **Samba** | Сетевое файловое хранилище (SMB/CIFS) с поддержкой обнаружения Windows (WSDD2) | `\\<IP_СЕРВЕРА>\<ПАПКА>` |
| **Caddy 2** | Обратный прокси (Reverse Proxy) с автоматическим выпуском SSL-сертификатов | Порты 80 / 443 |
| **Watchtower** | Автоматическое обновление Docker-образов в фоновом режиме | Фоновый демон |

## ⚡ Быстрый запуск

Выполните команду в терминале вашего Arch Linux:

```bash
curl -fsSLO [https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/main/install.sh](https://raw.githubusercontent.com/unknownpeace/arch-homelab-gateway/main/install.sh) && sudo bash install.sh

Требования:
​Установленный Arch Linux (или дистрибутивы на его основе).
​Права суперпользователя (sudo / root).
​Подключение к интернету.
​🛠 Режимы установки
​При запуске скрипт предлагает 3 сценария:
​Экспресс-установка (Всё включено)
​Развертывание всех сервисов на системном диске (/home/<user>/save).
​Локальные доменные имена (*.local).
​Автоматический выпуск внутренних SSL-сертификатов Caddy CA.
​Единый мастер-пароль для всех панелей и Samba.
​Расширенная настройка
​Выбор накопителя данных: системный диск или внешний/дополнительный HDD/SSD.
​Шифрование LUKS2 (Argon2id): защита данных на диске с возможностью авторазблокировки через ключ-файл при загрузке или ручной утилитой sudo homelab-unlock.
​Выбор режима SSL:
​*.local (внутренний CA) — без выхода в интернет.
​DuckDNS + Let's Encrypt — настоящий публичный Wildcard SSL без необходимости открывать порты 80/443 наружу.
​Выбор компонентов (можно отключить ненужные сервисы).
​Выбор внешнего вида qBittorrent (VueTorrent или классический).
​Сброс стека
​Корректная остановка контейнеров и очистка конфигурационных файлов без удаления скачанных файлов и образов Docker.
​🔒 Безопасность и SSL-сертификаты
​В скрипте реализовано два независимых варианта организации безопасного HTTPS-соединения:
​Вариант 1: Внутренний центр сертификации Caddy (*.local)
​Работает полностью локально, не требует регистрации доменов и доступа извне.
​Caddy выпускает локальный корневой сертификат caddy-root.crt.
​Скрипт автоматически экспортирует сертификат в сетевую папку:
\\<IP_СЕРВЕРА>\<ИМЯ_ШАРЫ>\certificates\caddy-root.crt
​Установите этот файл в «Доверенные корневые центры сертификации» на ПК или смартфонах, чтобы получить доверенный зелёный замок без предупреждений браузера.
​Вариант 2: Публичный Wildcard через DuckDNS + Let's Encrypt
​Выпускается единый официальный wildcard-сертификат вида *.yourname.duckdns.org.
​Проверка подлинности проходит через DNS-01 Challenge через DuckDNS API.
​Не требуется проброс портов на роутере: сервер остается полностью изолированным внутри локальной сети, но сертификат доверен всеми устройствами и браузерами «из коробки».
​🌐 Настройка шлюза для устройств в сети
​После завершения установки сервер может работать как прозрачный шлюз для других устройств в вашей локальной сети (ПК, телефоны, ТВ, консоли):
​IP шлюза (Основной шлюз / Gateway): укажите IP-адрес вашего Arch Linux сервера.
​DNS-сервер: укажите IP-адрес вашего Arch Linux сервера (порт 53 обрабатывается AdGuard Home, который фильтрует рекламу и передает трафик в Mihomo TUN).
​📂 Структура каталогов на сервере
/opt/homelab/
├── docker-compose.yml          # Главный конфигурационный файл стека
├── .env                        # Сохраненные переменные установки
├── adguard/                    # Конфигурация и рабочие базы AdGuard Home
├── mihomo/                     # Конфигурация ядра Mihomo и интерфейс MetaCubeXD
├── caddy/                      # Caddyfile, локальные сертификаты и хранилище ключей
├── qbittorrent/                # Конфигурации торрент-клиента и тема VueTorrent
├── vaultwarden/                # База паролей SQLite и вложения
└── backup_vaultwarden.sh       # Скрипт ежедневного горячего бэкапа базы
